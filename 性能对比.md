# JAX Profile：Ours vs Baseline 性能对比

说明：

- **E2E**：端到端延迟（`completed - scheduled`），单位 ms；越低越好。提升百分比 = `(baseline - ours) / baseline × 100%`（正值表示 ours 更快）。
- **吞吐 (thr)**：`throughput_requests_per_second`，单位 rps；越高越好。提升百分比 = `(ours - baseline) / baseline × 100%`。
- **Goodput**：SLO=200ms 下的 `slo_goodput_requests_per_second`，单位 rps；越高越好。提升百分比同上。
- Ours 数值后括号内为相对 baseline 的提升；baseline 列不加括号。
- 共同条件（各表另有差异见节内说明）：JAX、compile + warmup、多数为 200 req/rate。
